# FMS  
A Mobile-Based, AI-Powered File Management System  

## Introduction  
FMS is a mobile-based file management system enhanced with artificial intelligence. Traditional file managers depend on filenames, folders, and dates, which often do not reflect the actual content of files. FMS addresses this limitation by enabling search and organization based on file content rather than just metadata.  

## Features  
- Content-aware search in PDFs based on meaning, not only file name.  
- Automatic image captioning and text-based image search.  
- Image similarity detection to find related images.  
- Duplicate detection for exact and near-duplicate files.  
- On-device processing to ensure privacy and offline use.
